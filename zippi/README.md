# Zippi - Capital de Giro para MEI

App de capital de giro para microempreendedores (MEI).

## Estrutura

```
zippi/
├── index.html     # Página principal
├── styles.css     # Estilos
├── app.js         # Lógica da aplicação
└── README.md      # Este arquivo
```

## Como rodar

A partir da raiz do projeto:

```bash
npm run dev
```

Depois acesse: `http://localhost:3000/zippi/`

## Desenvolvimento

Edite os arquivos HTML, CSS e JavaScript conforme necessário.
